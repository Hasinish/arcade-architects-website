# purpose.md — The Bot Journey

## The One Line Version
Build an elite, modern, responsive architectural firm and portfolio showcase website for Arcade Architects displaying their premium exterior, interior, and exhibition design projects.

## Platform Goals
- Showcase Arcade Architects' high-end architecture and interior design projects (Chandina, Hazi Bari, Kotbari, Laksam, USA, Ford Exhibition, Apartments, Cafes, Luxury Residences).
- Present professional credentials, firm philosophy, and client reviews.
- Provide interactive project galleries, floor plan / 3D render viewers, and smooth consultation booking / lead capture.

## Success Metrics
- World-class architectural studio aesthetic (minimalist typography, dark/light architectural themes, grid layouts, fluid animations).
- Optimized high-resolution image delivery and responsive UI across desktop and mobile.
- Clean, extensible codebase ready for deployment.
