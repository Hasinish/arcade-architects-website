# Arcade Architects — Studio & 3D Visualization

High-fidelity, modern architectural studio and photorealistic 3D visualization platform for Arcade Architects, inspired by Bloom3D.

## Tech Stack
- **Framework**: React 19 + TypeScript (Vite)
- **Styling**: Tailwind CSS + Custom Architectural Glassmorphism
- **Motion & Interactions**: Framer Motion + Bloom3D-style slide mechanics
- **Icons**: Lucide React
- **Asset Processing**: D5 Render photorealistic visualizations & high-res exhibition archives

## Features
- **Cinematic Hero**: Ambient architectural showreel background with dynamic dual sliding-text CTA buttons.
- **Interactive Portfolio**: Filterable project gallery (Exterior, Interior, Exhibition, 3D Visualization) with full lightbox modal and architectural specs sheets.
- **Core Services Matrix**: Detailed capabilities overview with live dynamic sticky render previews.
- **Studio Philosophy & Metrics**: Clean architectural typography with animated key performance counters.
- **Why Work With Us**: Numbered architectural grid highlighting precision engineering and turnaround times.
- **Google Reviews Integration**: Verified client testimonials with direct link to Arcade Architects Google Maps review profile.
- **Interactive Project Inquiry**: Multi-step project brief builder with celebratory submission animation.
- **Consultation Scheduling**: 20-minute discovery call booking module with Google Meet & WhatsApp options.

## Getting Started

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Production build
npm run build
```
